fusion360-football

Generates a parametric football (soccer ball) as a truncated icosahedron: 12 pentagon panels and 20 hexagon panels, each created as its own independent, 3D-printable solid body.

Running the command

  1. Open or create a design in Autodesk Fusion.
  2. On the Solid tab, open the Create menu and click Football.
  3. Set the parameters below and click OK. The 32 panels are created in the active design, named Pentagon_01…Pentagon_12 and Hexagon_01…Hexagon_20.

In an Assembly document each run creates its own Football component (then Football (2), …), so several balls can live in one design. In a Part document (single-component) the bodies are created in the root component instead.

Parameters

ParameterDefaultDescription
Hexagon side44 mm Edge length of the truncated icosahedron. Every edge (pentagon and hexagon) has this length.
Face deep5 mm Panel thickness, measured at the edges.
Print tolerance (gap)0 mm Total clearance left between adjacent panels for 3D printing. 0 = panels touch exactly; around 0.1 mm is a typical real-world fit.
External faceFlat Flat keeps each panel's outer face planar (a faceted ball). Rounded carves the outer face with the ball's circumsphere so the surface reads as smoothly round.
Pentagon color0, 0, 0 (black) RGB (0–255) applied to the pentagon bodies.
Hexagon color255, 255, 255 (white) RGB (0–255) applied to the hexagon bodies.

Notes for 3D printing

  • Each panel is a separate solid body, so you can export each one to STL individually.
  • The mitered side faces are cut at each edge's true dihedral angle (138.19° where a hexagon meets a hexagon, 142.62° where it meets a pentagon), so the printed pieces assemble flush.
  • Use the Print tolerance parameter to introduce a small gap so the pieces fit together after printing.
