# fusion360-football

A Fusion 360 Add-In that generates parametric footballs (soccer balls), built as a
truncated icosahedron with a dialog for size and panel parameters.

## Status

Early development.

## Requirements

- Autodesk Fusion 360
- Python (bundled with Fusion 360's API)

## Installation

1. In Fusion 360, go to **Utilities > Add-Ins > Scripts and Add-Ins**.
2. Click the green **+** next to Add-Ins and select this repo's folder.
3. Run the add-in from the Add-Ins list.

## Development

This add-in follows the standard Fusion 360 Add-In layout (manifest `.manifest`
file + Python entry point).
